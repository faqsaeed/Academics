## Getting Started

To set up and use this repository, follow these steps:

Clone the Repository

```bash
git clone https://github.com/faqsaeed/Academics.git
```

Navigate to the Repository

```bash
cd Academics
```

Open a Specific Semester

```bash
cd [FolderName]
```

(Replace `FolderName` with the folder you want to explore.)
Open in Your Preferred Editor

```bash
code .  # Opens in VS Code
```

## Usage

### Viewing Course Material

- Navigate through the folders and access relevant PDFs, assignments, and lecture slides.

### Running Code (if applicable)

For programming-related coursework, ensure you have the necessary compilers or interpreters installed.
Running Python Code

```bash
python3 filename.py
```

Running C++ Code

```bash
g++ filename.cpp -o output
./output
```

Running Assembly Code (NASM)

```bash
nasm  file.asm -o file.com
afd file.com #For Debuging
file.com #To Execute Directly
```

(Modify these commands based on your coursework requirements.)
